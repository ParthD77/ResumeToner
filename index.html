Prefer to build it yourself?

  1. Install Node.js 20 or newer and clone the repository.
  2. Run npm install and npm test.
  3. On Windows, run npm run desktop:build:win.
  4. Find the installer in the versioned desktop-release-* folder.

Unsigned Windows and Mac builds are best suited to informed testers and technical early adopters. Users do not need developer accounts, but their operating system will show a warning or require an explicit exception. Signed—and on macOS, notarized—builds provide a substantially better public onboarding experience.

Option 2 · Chrome extension

Capture the job page and use Gemini.

The extension reads a job posting only when you ask it to, sends the resume and job details to Google Gemini using your own key, and gives you an ATS-friendly PDF to review and export.

1

Add it to Chrome

Open the official Chrome Web Store listing, choose Add to Chrome, and pin Resume Toner from the Extensions menu if you want quick access.

2

Add your Gemini key

Create your own key in Google AI Studio. Open Resume Toner, paste the key into setup, and save it. Keep it private—never share it in an issue.

3

Open a job and analyze

Add or import your resume, open a job posting in Chrome, and choose Analyze. Review every generated change before exporting your PDF.

What gets sent: when you invoke an AI action, the extension sends the relevant resume content and job listing to Google's Gemini API. Review Google's pricing and data-use information and terms before use.

Privacy Policy

Last updated: September 22, 2026

Resume Toner is a local-first, open-source desktop app with an optional Chrome extension. It has no developer-operated backend, user accounts, analytics, advertising, or telemetry. The developer cannot remotely view users' resumes, application data, or API keys.

Official installers and disk images are distributed through GitHub Releases. GitHub may process download metadata under its own privacy terms; Resume Toner does not receive resume contents or application data merely because a user downloads a release. Code signing and Apple notarization, when used, verify the publisher and software integrity and do not send resume content to the developer.

Information handled

Resume Toner handles information that the user chooses to provide:

  • resume content, including identity, contact, location, education, work history, projects, and skills;
  • PDF files selected for resume import;
  • career evidence and optional user-confirmed chatbot context;
  • job postings pasted into the desktop app or captured after the user clicks the extension;
  • LaTeX source, ChatGPT prompts and responses used in the desktop workflow; and
  • a user-provided Google Gemini API key when the optional extension is used.

Local storage

Desktop resumes, jobs, pasted responses, review decisions, settings, and recent snapshots are stored in the app's local storage on the user's device. Extension data is stored in Chrome-managed storage. Neither is encrypted or a cloud backup. The extension's Gemini API key is stored locally, is not synchronized, is excluded from backups, and is not sent to the Resume Toner developer. Someone with access to an unlocked device or Chrome profile may be able to recover locally stored information.

Transfers through the desktop workflow

The desktop app prepares a prompt from the resume and job information supplied by the user. The user reviews and manually pastes that prompt into their own ChatGPT conversation, then manually pastes the response back into Resume Toner. Resume Toner does not operate an OpenAI API key or backend. Information submitted to ChatGPT is handled under the user's OpenAI account, plan, settings, and applicable terms.

Transfers to Google Gemini

Resume Toner connects only to Google's Gemini API and only in response to a user action. The extension uses the user's own Gemini API key.

  • PDF import sends text extracted locally from the selected PDF to Gemini so it can be structured for review.
  • Analyze sends the full resume, saved career evidence, optional user-confirmed context, and selected job listing to Gemini.
  • Compact sends relevant resume content and job requirements to Gemini.

Google's current Gemini API terms and pricing and data-use table distinguish between free and paid services. Google may use prompts and responses submitted through unpaid services to improve its products, including machine-learning technologies. Google states that prompts and responses submitted through paid services are not used to improve its products. Resumes can contain sensitive personal information, so users should review Google's current terms and choose an appropriate account and billing arrangement before sending data. Resume Toner does not use remote code; all executable extension code is included in its package.

How information is used

Information is used only to import, review, tailor, preview, export, and locally organize resumes. Resume Toner does not sell user data, use it for advertising, determine creditworthiness, or transfer it for purposes unrelated to its resume-tailoring function. No developer or other human is permitted to read user data through Resume Toner.

Retention and deletion

Information remains on the user's device until the user deletes it, clears the relevant application data, or uninstalls the app or extension. Desktop users can export and restore a private local backup. Extension users can delete application records, delete local structured data, forget the API key, and export a backup that excludes the API key. Files downloaded by the user remain wherever the user saved them.

User responsibility

Resume Toner checks whether suggestions are supported by information the user supplied; it cannot independently verify that resume claims or chatbot memories are true. Resume Toner provides automated drafting and editing suggestions only. Users must review and verify all generated content before using or submitting it and must not submit false, misleading, fraudulent, or unlawful information. Resume Toner does not guarantee employment, interviews, ATS performance, eligibility, or the accuracy of AI-generated output.

Eligibility and provider terms

Resume Toner is for users aged 18 or older. Google describes Gemini API access as a developer service for professional or business purposes. If a user is in the European Economic Area, Switzerland, or the United Kingdom, Google's current Gemini API terms require Paid Services; the user must supply a key connected to a Cloud project with active billing. Provider terms and regional availability may change, so users must review Google's current terms before use.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Questions

General questions and issues can be submitted through the public source repository. Do not post resumes, API keys, or other private information in a public issue. Privacy and security reports may be sent privately to parthdhroovji1@gmail.com.
